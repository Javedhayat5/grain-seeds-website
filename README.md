🌱 Sprout & Co. — Premium Grain Seeds

A modern, responsive, single-page agricultural website built with HTML, CSS, and Vanilla JavaScript. The project combines a cinematic scrolling experience with an elegant product catalog, interactive shopping cart, and mobile-friendly interface.
